# Privacy Policy

This is a personal, non-commercial tool used to manage YouTube channels that
I personally own and operate. It is not a public product, has no other
users, and is not distributed to anyone else.

## What this tool does

This application uses the YouTube Data API v3 to upload videos to my own
YouTube channels and to set their title, description, tags, and scheduled
publish time.

## What data it accesses

This tool accesses YouTube account data only through Google's standard
OAuth 2.0 authorization flow, limited strictly to the scopes required to
upload and manage videos on channels I personally own. It does not access,
collect, request, or store data belonging to any other person or channel.

## What data it stores

Authorization tokens are stored locally on my own computer so the tool can
upload on my behalf without repeated logins. No data collected by this
tool is transmitted to, sold to, or shared with any third party. The tool
runs entirely locally, has no backend server, and has no analytics or
tracking of any kind.
